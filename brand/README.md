# duck's mark

duck's mark is a duck's track: a webbed foot with three toes, drawn as one solid shape.

| File | What it is | Use it |
| --- | --- | --- |
| `duck-track.svg` | The mark with its three toe lines cut out, filled with `currentColor` | At 24 px and larger |
| `duck-track-small.svg` | The same foot without the toe lines | Below 24 px, where the toe lines blur to grey |
| [`duck-icon.png`](duck-icon.png) | The mark in ink on a birch tile, 512 px square | The Buzz plugin's icon, and anywhere a square picture is wanted |

Both SVGs share one view box, so they swap without moving. Set the colour with CSS `color`, or as the
`fill` of the path.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#1E3246` | The mark on a light ground |
| Birch | `#F2EFE6` | The mark on a dark ground, and the icon's tile |
