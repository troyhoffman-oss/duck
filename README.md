# duck

duck gives every person at a small firm a coworker that moves their work forward without being asked and knows when to stay quiet.

It is open source and runs on the firm's own Linux server. A coworker watches whatever the firm plugs in, mail, a calendar, any MCP server, and comes back with finished work or a decision to make. People talk to it where they already talk: Buzz, text, email. It is built on goose, which it runs unmodified.

duck is pre-release and being rebuilt from one design. [ROADMAP.md](ROADMAP.md) says which parts work today.

## Setting it up

An admin does not set duck up by hand. Point the coding agent you already use, such as Claude Code or Codex, at this repo and ask it to set duck up for your firm. It reads [SETUP.md](SETUP.md), asks you what only you can decide, and does the rest.
